# Testbook-style Mock Test App (Flutter)

Yeh ek ready-to-build Flutter project hai jo Android APK aur Windows (.exe) dono ke liye taiyar hai.

### Features
- Responsive Layout (Mobile portrait view & Desktop widescreen portal)
- Timer Countdown (Auto-submit functionality)
- Question Palette (Jump to question, answered, review & skip status)
- Scorecard Calculation (+2.0 marks for correct, -0.5 marks for wrong)
- Complete Solution & Explanation view

### Kaise Use Karein:
1. GitHub par nayi repo banayein aur is folder ke files upload karein.
2. Actions tab me jate hi APK aur Windows .exe automatic compile ho jayenge.
3. Ya local PC me: `flutter run -d windows` ya `flutter run -d android` chalayein.
